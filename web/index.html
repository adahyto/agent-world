      Podłącz swoje Claude Code

      Sesje Claude Code z laptopa albo serwera pojawią się na tej mapie jako dziki. Wystarczy jedna linia w terminalu tego komputera (macOS, Linux, Windows przez WSL).

      Co hook wysyła z tego komputera Przycinanie robi hook na Twoim komputerze (python3 albo jq). Bez nich zdarzenie idzie w całości, a serwer od razu odrzuca to, czego tryb nie obejmuje, i niczego z tego nie zapisuje.

      Wklej w terminalu tego komputera

      
        
      
        
      Token jest w poleceniu i widać go tylko teraz. Skrypt sprawdzi go, zapisze hook w ~/.agent-world-remote/ i dopisze go do ~/.claude/settings.json (inne hooki zostają, kopia pliku obok). Potem uruchom claude jak zwykle; działające sesje uruchom ponownie.

        Jak czytać mapę
        Każda Twoja sesja Claude Code to dzik z watahy. Barłóg w lesie to projekt, miejsca na polanie i za drogą to narzędzia, a pod bramą bazy dzik czeka na Twoją zgodę.
        

  
        Dane pochodzą z hooków Claude Code z podłączonych komputerów (przycisk „podłącz komputer”). Każdy zalogowany widzi tylko swoje sesje. Sesje zakończone znikają z mapy po 10 minutach, oś czasu pamięta 24 godziny. Pora roku i dnia na mapie idą za zegarem serwera. Prywatność.

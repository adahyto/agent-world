Agent World · for Claude Code

Your Claude Code sessions as a pack of wild boars

A live pixel-art map of everything your agents do. Each session is a boar, each subagent a piglet, each tool a feeding spot. When Claude needs your permission, its boar comes to your camp with a red “!”, so you see at a glance who works and who waits.

What you see

Every session, liveA boar per Claude Code session, named after its project, with a den in the forest. Subagents follow as piglets.
What it is doingThinking, reading, editing, running a command, searching the web: each tool has its own spot on the map, with a bubble over the boar.
Who waits for youA request for permission or an idle session brings the boar to your camp. Click it for its timeline and, if you chose to send them, the prompt and the last reply.
Several computersConnect a laptop, a server and a VPS with one line each; all their sessions land on one map.

Try it in two minutes

  1. Open dziki.doner.cloud and log in with your email: you get a one-time code, no password and no account to set up.
  2. Click “podłącz komputer” (connect a computer) and choose what to send: status (states and tool names only) or full (also the prompt, the reply and a short tool detail).
  3. Paste the line it gives you into a terminal on the computer where you run Claude Code. It adds hooks to ~/.claude/settings.json; the same script with --usun removes them.
  4. Start Claude Code as usual. Your boars appear within a second.

The hosted version is a free guest account for 24 hours: then its tokens, sessions and history are deleted. Everyone sees only their own sessions. The interface is in Polish for now. Privacy: what is kept and for how long.

Host it yourself

Node and curl, nothing else: a collector that takes Claude Code's hook events and serves the map, and a hook script. MIT licence.

git clone https://github.com/adahyto/agent-world ~/agent-world
node ~/agent-world/collector/server.js     # listens on 127.0.0.1:7777
# add the hooks from hooks/settings.hooks.json to ~/.claude/settings.json, then:
ssh -L 7777:127.0.0.1:7777 you@your-server  # open http://localhost:7777
  • Events can contain prompts and parts of replies: do not expose the collector without authentication. The hosted version sits behind Cloudflare Access.
  • No raw event log by default; the state of the map is kept in ~/.agent-world/state.json.
